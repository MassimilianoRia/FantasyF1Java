# Fantasy F1 🏎️

Fantasy F1 is a desktop application developed in **Java** and **JavaFX** for managing a Formula 1 fantasy championship.

Users can create teams, join leagues and compete through points calculated from race weekend results. The application also provides an administrative interface for managing seasons, drivers, constructors, races and results.

## Technologies

* Java 21
* JavaFX
* MySQL
* JDBC
* Gradle
* JUnit

## Run

```bash
./gradlew run
```

Alternatively, the project includes the executable `FantasyF1Java.jar`.

## Project

Developed as a university project for the **Computer Engineering and Science** degree course at the University of Bologna.
